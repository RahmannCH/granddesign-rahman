# Grand Design — Muhammad Nur Rahman

Standalone assignment website for HIMAKOM ULM cadre training.

- `/` serves `grand-design.html` through the Vercel rewrite in `vercel.json`.
- `/grand-design.html` remains available as the canonical document route.
- The page uses only static HTML, CSS, and local image assets.
- No JavaScript, build step, package installation, or homepage dependency is required.
